# 同じ場所で見た目が変化した石垣の写真ペア（熊本城）

作成日: 2026-11-07 / 写真の出典: Wikimedia Commons

## 探し方
1. Commonsから熊本城関連カテゴリと城周辺の位置情報つき写真、各地の城の石垣カテゴリの写真を集めた（823枚）
2. 全写真で特徴点（RootSIFT）を照合し、幾何学的に整合する組（RANSACで40点以上一致）を「同じ場所」と判定 → 635組
3. 撮影日が1年以上離れた組を変化の大きさ順に並べ、目視で確認して6組を選んだ

## ファイル
- `compare/P01〜P06.jpg` … 前後の写真を並べた比較画像（クレジット表記つき）
- `photos/` … 比較に使った写真（前=A、後=B、長辺 約960px）
- `change_pairs.csv` … 6組の場所、変化の内容、確度、撮影日、ライセンス、作者、Commons URL
- `all_same_place_pairs.csv` … 同じ場所と判定した全635組（目視確認前。天守閣の組が多い）
- `_raw/` … 元データ（不要なら削除可）

## 選んだ6組
| ID | 場所 | 変化 | 確度 |
|---|---|---|---|
| P01 | 東竹之丸 四間櫓・源之進櫓の下 | 2012年→2026年：石垣の一部が崩れ、中の栗石がむき出しになっている | 強 |
| P02 | 本丸周辺の高石垣 | 2014年→2026年：隅部が崩落し、保護材で覆われている | 強 |
| P03 | 天守台 | 地震1.5か月前→2023年：復旧後の石垣が明るい色に見える（光の条件の差も含む） | 強 |
| P04 | 天守台（別角度） | 2011年→2022年：P03と同じ変化 | 中 |
| P05 | 天守と本丸の建物 | 2014年→2022年：建物の白壁の漆喰が剥がれている（石垣の変化は小さい） | 弱 |
| P06 | 戌亥櫓 | 地震4日後→2018年：崩れたままで変化が少ない（比較用） | 変化小 |

## 注意
- 撮影日はCommonsのメタデータ（EXIFまたは説明文）の値。
- 自動照合には誤判定もある（例：江戸城の石垣と熊本城の石垣が「同じ場所」と判定された組があり、除外した）。all_same_place_pairs.csv は未確認の候補として扱うこと。
- 比較画像を公開するときは、両方の写真のクレジット（attribution_before/after）を表示する。CC BY-SA の写真を含む比較画像を改変・再配布する場合は CC BY-SA の条件に従う。
